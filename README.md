# Ticker Research

Fundamental company-research materials and source filings, organized for repeatable equity analysis.

## Repository layout

| Path | Contents |
| --- | --- |
| `research/reports/` | Dated company-research reports in Markdown. |
| `models/` | Reproducible valuation models and analysis scripts. |
| `sources/filings/` | Primary-source company filings cited by the reports. |

## Conventions

- Use ISO dates (`YYYY-MM-DD`) at the beginning of report filenames.
- Keep reports in Markdown and preserve primary documents in `sources/filings/`.
- Cite source documents and distinguish reported facts from analysis.

This repository supports coursework and independent learning; it is not investment advice.
